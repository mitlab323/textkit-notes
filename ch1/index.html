PART 1

這門科學在幹嘛？難度 ★

Is pattern recognition important?

一句話定義：模式辨認（pattern recognition）是以「把物件分類到若干類別」為目標的科學。依應用不同，物件可以是影像、訊號波形或任何需要分類的量測值——統稱 pattern（樣本）。

pattern（樣本） → 特徵向量量測 → 類別分類器
本章的總骨架：量測 → 特徵向量 → 分類器 → 類別（公式列改用 HTML 排版，避開 KaTeX 對中文缺乏字型度量的問題）

課本說：模式辨認是「大多數機器智慧系統的核心零件」——工業自動化與資訊檢索把這個領域推上工程應用的浪頭。

六個應用故事（課本 1.1）＝ 六個就業開口

🏭 機器視覺

輸送帶製品即時檢驗「有缺陷/無缺陷」；組裝線認出「螺絲起子類」「板手類」→ 機械手臂抓取。

🔤 字元辨識 OCR

掃描 → 分割 → 分類每個字元。應用：支票閱讀、郵局分信、線上/離線手寫。

🏥 電腦輔助診斷

X 光、CT、超音波、ECG/EEG。課本例：乳癌攝影有 10–30% 漏診 → 系統當「第二意見」。

🎧 語音辨識

開口打字（比打字員快 2 倍）、遠端操控、輔助身心障礙者。

📊 資料探勘 & 內容檢索

CBIR（影像簽章檢索）、哼歌找音樂、DNA 序列比對。手動註記行不通 → 相似度搜尋。

🧬 生物辨識與人機互動

指紋、簽名、人臉、手勢；MPEG-7「搜尋所有『人物 X 在笑』的影片場景」。

🧠 口訣：「看缺陷、讀文字、助診斷、聽語音、挖資料、認人臉」——六個故事，就是今日 CV／語音／資料科學工程師的專案長相。

特徵、特徵向量與分類器 難度 ★★ 核心

Features, feature vectors & classifiers

課本用一個「醫療影像分類」小故事，把整本書最重要的三個零件一次講完。

2.1 故事：良性 vs 惡性病灶

兩張影像，各有一塊區域：圖 a → 良性（class A），圖 b → 惡性（class B）。我們手上有一整個影像資料庫，每張的類別已知。

第一步：找出可量測、能區分兩類的數量。課本量了「區域平均亮度 mean」與「亮度標準差 std」——把每張圖畫成 2D 散點圖（課本 Fig 1.2）：

現在來一張新圖（圖中星號 ∗）：量測後畫進圖裡——合理判斷：它比較可能是 class A。

🎯 這三個零件正式登場：特徵（feature）＝量測值；特徵向量＝一組特徵；分類器＝那條「刀」（決策線）。

2.2 三個零件的正式定義

$$\mathbf{x}=[x_1,x_2,\ldots,x_l]^{T}$$
特徵向量：每個 pattern（樣本）唯一對應一個 x（課本 1.2）
術語白話課本重點
特徵 Feature從樣本量測出的「有意義數字」（本例：mean、std）問題依賴：怎麼產生？是四大問題之一
特徵向量 x把 $l$ 個特徵疊成一支「數字串」被視為隨機向量（量測噪音 + 個體差異）
分類器 Classifier把特徵空間切成類別區的「刀」2D 是決策線；$l$ 維是決策面/超平面
誤分類 Misclassification分錯了決策不保證正確——所以才要「評估」
訓練樣本 Training patterns類別已知、用來設計分類器的樣本監督式學習的燃料

2.3 分類系統的四大問題（設計循環）

#問題設計階段對應本書章節
1特徵怎麼產生？feature generationCh6–7（★你學過的 Ch7！）
2特徵數量 $l$ 取多少最好？feature selectionCh5
3分類器怎麼設計（照什麼準則）？classifier designCh2–4

三種學習方式 難度 ★★ 核心

Supervised vs Unsupervised vs Semi-supervised

差別只有一件事：手上有沒有標籤？

監督式 Supervised非監督式 Unsupervised（叢聚）半監督式 Semi-supervised
標籤訓練樣本全部有完全沒有少量有 + 大量無
目標設計分類器發掘資料群組結構（clustering）借無標籤資料改善設計
課本範例病灶良惡分類多光譜遙測：辨識森林/土壤/水體must-links / cannot-links 約束
口訣「考卷有答案」「自己找同類」「幾題有答案，其餘靠推」
本書章節Ch2–10Ch11–16Ch10

遙測範例（課本 1.3）：

衛星感測器量測地表在多個波段的反射能量（可見光–紅外：土壤礦物/含水量、水體沉積、植被含水量…）→ 每個格點形成特徵向量 → 叢聚演算法把特徵空間自然聚成的群找出來 → 分析者用參考地面資料幫每個群「命名」（森林/土壤/水體…）。

📌 非監督式的兩個關鍵議題：①「相似性」怎麼定義（度量選擇）；② 用哪種叢聚演算法（不同演算法可能給不同結果，需專家解讀）。
🎯 半監督式的實務價值：標籤很貴的領域（醫療、法務）——標 100 張圖的錢，可以用 100 張標籤 + 9,900 張無標籤把系統做得更好。叢聚版半監督 = 把標籤變成「must-link（同群）」與「cannot-link（不同群）」的約束。
互動 Demo 2｜監督 vs 分群：同一批資料，兩種玩法k-means 單步執行；再看「如果標籤存在」會是什麼樣

按「初始化中心」開始。每步：① 每個點指派到最近的中心 → ② 中心移到該群平均。重複直到收斂。

💡 對照「顯示真標籤」：分群結果與真標籤通常不完全一樣——因為非監督式沒有答案可對，能對上的程度取決於資料本身分得多開。
